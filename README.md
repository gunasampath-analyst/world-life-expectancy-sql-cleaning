# World Life Expectancy — SQL Practice

A beginner-friendly MySQL practice project focused on cleaning and transforming a World Life Expectancy dataset.

## 📌 About the Project

This project was created to practice SQL concepts commonly used in data cleaning and analysis.

The dataset contains information related to life expectancy, countries, development status, and other country-level attributes.

## 🛠️ SQL Skills Practiced

- Data Cleaning
- Duplicate Detection & Removal
- Handling Missing Values
- `UPDATE` statements
- `JOIN`
- `CASE` statements
- Aggregate Functions
- `GROUP BY`
- Window Functions
- Data Transformation

## 📂 Files

- `World_Life_Expectancy.sql` — SQL queries used for data cleaning and transformation
- `World_Life_Expectancy.csv` — Dataset used for practice

## 🎯 Purpose

The main goal of this project was to strengthen practical SQL skills by working with a real-world dataset and performing common data-cleaning tasks.
